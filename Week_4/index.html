What was built, why, and all live deliverables
✅
Week 1 Checkpoint — Complete All 5 API endpoints live (200 OK). React frontend deployed on S3. Swagger docs working. 3 CloudWatch alarms active. Email alerts configured via SNS.

VoltStream models a real-world Prosumer scenario — a household that both consumes electricity from the utility grid and generates solar energy via rooftop panels, selling surplus power back to the grid. The entire application was built from scratch and deployed to AWS using a fully serverless architecture. Zero servers were provisioned, zero infrastructure needs to be maintained, and the system scales automatically.

Complete Request Flow
1
User opens the S3 website URL
S3 returns index.html + React JS bundle — pure static delivery, no server involved.
2
React boots and starts polling
Reads VITE_API_URL from bundle, starts polling Live Dashboard every 4 seconds.
3
fetch() sends HTTPS request
GET to https://p0zatmquc0.execute-api.us-east-1.amazonaws.com/prod/api/v1/dashboard/live
4
API Gateway invokes Lambda
Matches ANY /{proxy+} and invokes voltstream-api Lambda with Payload Format 2.0 event.
5
Lambda cold-start or warm reuse
~400ms first request (cold start) or <50ms for subsequent requests using warm container.
6
Mangum translates event to ASGI
Mangum(app, lifespan="off") receives the Lambda event and translates it to an ASGI HTTP scope that FastAPI understands.
7
FastAPI handles the route
Matches /api/v1/dashboard/live to get_live_dashboard(), generates random solar/grid values, serializes LivePowerStatus model to JSON.
8
Response returns to browser
API Gateway returns JSON → React re-renders gauges and sparkline in real-time.
9
CloudWatch captures metrics
Logs RequestId, Duration, MemoryUsed for every invocation. If errors ≥ 5 in 5 min → alarm fires → SNS publishes → email sent.

The /openapi.json Fix
⚠️
Critical Issue Resolved Swagger UI fetched /openapi.json (without /prod prefix) which returned 404. Fixed with custom routes.
app = FastAPI( docs_url=None, # disable default /docs redoc_url=None, openapi_url=None, ) # Custom routes with full /prod path @app.get("/docs") def custom_docs(): return get_swagger_ui_html( openapi_url="/prod/openapi.json", )

Returns all 8 registered smart home devices with power draw and on/off state

PATCH/api/v1/devices/{id}
Toggle a device on/off. Returns updated device or HTTP 404 if device ID not found
GET/api/v1/billing/summary
Returns current balance, projected bill, budget limit, and over-budget alert flag
{"current_balance":37.06,"projected_bill":65.4,"budget_limit":80.0,"alert":false}

The 3 CloudWatch Alarms
✅
VoltStream-Lambda-Errors
Metric: Errors (Sum) · Threshold: ≥ 5 errors · Period: 5 min · State: OK
Detects Lambda function throwing unhandled exceptions — 500 errors
⏱️
VoltStream-Lambda-Duration
Metric: Duration (Avg) · Threshold: ≥ 3000ms · Period: 5 min · State: INSUFFICIENT_DATA
Detects slow API responses — cold starts or heavy processing
🚫
VoltStream-Lambda-Throttles
Metric: Throttles (Sum) · Threshold: ≥ 1 throttle · Period: 1 min · State: INSUFFICIENT_DATA
Detects Lambda hitting concurrency limit — too many parallel requests
ℹ️
INSUFFICIENT_DATA is expected Duration and Throttles alarms show this state because they need traffic to collect data points. After the Live Dashboard polls the API for a few minutes, all alarms transition to OK automatically.

09
Issues Encountered & Resolutions
Every problem hit with root cause and fix
🐍
Windows pip build — pydantic_core crash
Symptom
"No module named pydantic_core._pydantic_core"
Root Cause
Windows .pyd binaries incompatible with Lambda Linux runtime
Resolution
Rebuilt inside AWS Lambda Docker image: public.ecr.aws/lambda/python:3.12
🔗
Stage prefix 404 — All endpoints returning Not Found
Symptom
All endpoints returned {"detail":"Not Found"}
Root Cause
API Gateway passes /prod/api/v1/... but FastAPI routes match /api/v1/...
Resolution
Added api_gateway_base_path="/prod" to Mangum, then switched to custom /docs route
📚
Swagger docs 404 — /openapi.json path mismatch
Symptom
"Failed to load API definition — 404 /openapi.json"
Root Cause
Swagger UI fetches /openapi.json but endpoint is at /prod/openapi.json
Resolution
Disabled default docs, created custom /docs route with openapi_url="/prod/openapi.json"
💻
PowerShell && syntax — token not valid
Symptom
"The token && is not valid"
Root Cause
PowerShell does not support bash && chaining syntax
Resolution
Ran each command on a separate line
🐳
Docker not running — failed to connect to Docker API
Symptom
"failed to connect to docker API"
Root Cause
Docker Desktop was not started
Resolution
Opened Docker Desktop and waited for whale icon in system tray
🪣
Bucket name typo — NoSuchBucket error
Symptom
"NoSuchBucket" error on S3 upload
Root Cause
Bucket name had _ID suffix appended accidentally
Resolution
Corrected to voltstream-deployments-764395350322
